# Results Directory

This folder stores analysis result files.

## Folder Structure

### LDSC_Output/
LDSC partitioned heritability analysis output files

### Plots/
- Manhattan plots (by cell type)
- Enrichment visualizations
- Comparison analysis plots

### Tables/
- Aggregated result CSV files
- Significant SNP lists
- Cell type-specific analysis results

## File Size Notice

Most result files are large and are excluded in .gitignore.
Key results can be verified through README and summary files.
